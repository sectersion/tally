Tally measures how long you really work with an AI coding agent. It
turns your activity into a verified record of time, so the hours you
report can be checked instead of taken on trust.

What is captured: when you send a prompt, when you approve or
interrupt the agent, when you run tests, when you commit, and how
long the keyboard and mouse were idle. Only counts and lengths are
kept, never the words.

What is never captured: prompt text, file contents, commands, window
titles, web addresses, keystrokes or screenshots.

What can leave this computer: nothing, until you choose it.
If you link a project to the Tally server, its ledger entries
(project name, action type, time, seconds, reason codes and numeric
features such as prompt length) and the ledger head hashes are
uploaded.
If you publish, badge data (verified hours per project) is published.
Only if you run `tally submit`, scrubbed session text for that one
submission is sent for review.

See your data: run `tally status`.

Stop it: run `tally stop`.

Remove it: uninstall the extension and run `tally service
uninstall`. Your data stays on disk unless you add `--purge`.

Questions: ask the person who set up Tally for you, or the Tally
maintainers at https://github.com/sectersion/tally.
