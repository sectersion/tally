# Replay samples

These three sessions are **SYNTHETIC**: generated by `crates/tally-evidence/examples/synth_sessions.rs` from hand-written event lists. They show how the comparator behaves; they are not measurements and must not be presented as real data. The Hackatime-style figure is derived from the events (every non-idle event is a heartbeat, an agent run adds one every 30 s, 2-minute timeout), not a real Hackatime export.

A real teen session, with their consent, is added by a human: export their events as NDJSON and, if available, their Hackatime heartbeats, then run `tally-evidence replay <events.ndjson> --heartbeats <file>`.

Regenerate: `cargo run -p tally-evidence --example synth_sessions -- docs/evidence/replay`.
